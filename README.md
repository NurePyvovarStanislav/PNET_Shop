# PNET_Shop

Навчальний вебзастосунок для обліку роботи магазину. Розроблено в рамках курсу **«Робота з даними на платформі .NET»** (лабораторний практикум).

## Призначення

Застосунок дозволяє вести облік:

- **відділів** магазину;
- **постачальників**;
- **товарів** (ціна, кількість, відділ, постачальник);
- **чеків**;
- **продажів** (зв’язок товару з чеком).

Для кожної сутності доступні операції **CRUD** (перегляд, створення, редагування, видалення). Для товарів реалізовано **пошук** за назвою, виробником, відділом і постачальником.

## Технології

| Компонент | Рішення |
|-----------|---------|
| Платформа | ASP.NET Core (.NET 10) |
| UI | Razor Pages, Bootstrap 5 |
| БД | Microsoft SQL Server |
| ORM | Entity Framework Core (Code-First, міграції) |
| Доступ до даних | Патерн **Repository** + **Dependency Injection** |
| Валідація | DataAnnotations |
| Логування | `ILogger` (Console, Debug) |

Авторизація та Identity **не використовуються** — це навчальний застосунок без входу в систему.

## Структура проєкту

```
PNET_Shop/
├── Data/           — ShopDbContext
├── Models/         — Department, Supplier, Good, Check, Sale
├── Repositories/   — інтерфейси та реалізації репозиторіїв
├── Migrations/     — міграції EF Core
└── Pages/          — Razor Pages (CRUD для кожної сутності)
```

## Запуск

1. Встановіть [.NET SDK](https://dotnet.microsoft.com/download) та **SQL Server** (Express або повна версія).

2. У `PNET_Shop/appsettings.json` змініть рядок підключення `ShopDbConnection` на свій сервер:

   ```json
   "ShopDbConnection": "Server=ВАШ_СЕРВЕР;Database=ShopDB_EF;Trusted_Connection=True;TrustServerCertificate=True;"
   ```

3. Застосуйте міграції (з каталогу `PNET_Shop`):

   ```bash
   dotnet ef database update
   ```

4. Запустіть застосунок:

   ```bash
   dotnet run
   ```

5. Відкрийте в браузері адресу з консолі (зазвичай `https://localhost:7xxx`).

## Особливості

- Первинні ключі для відділів, постачальників і чеків генеруються базою даних (IDENTITY).
- При видаленні перевіряються залежності (наприклад, відділ з товарами не видаляється).
- Помилки введення відображаються на формах завдяки валідації моделей.
